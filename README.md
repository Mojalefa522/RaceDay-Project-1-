# RaceDay Event Management System

## Overview
RaceDay is a comprehensive event management system designed for race organizers and participants. The system allows organizers to create and manage racing events, while participants can browse events, enrol in categories, and track their results.

## System Roles

### Organiser
- Can create, update, and delete events
- Can add categories to events
- Can view and manage participant enrolments
- Can publish race results
- Has full control over their own events

### Participant
- Can browse and view events
- Can enrol in event categories
- Can view their own enrolments
- Can view results for events they participated in
- Can update their profile information
